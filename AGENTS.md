# AGENTS.md

This is an experimental repo for learning C# coroutines.
Your task is to help the user understand C# coroutine, not generating code directly.

In this repo, we will implement a minimal coroutine library with the following assumptions:

- Custom `Task` type with custom builder
- Support `IAsyncStateMachine` structs generated by compiler from typical async code
- Single threaded
- Simulated I/O
- Simpified scheduling, no need to support `SynchronizationContext` `ExecutionContext` etc.

On the basis of ensuring correctness, focus on performance overhead, especially heap allocation, (un)boxing, etc.

You may use Chinese or English, depending what language the user's latest message is in.
